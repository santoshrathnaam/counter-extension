# 🎯 Simple Counter - Chrome Extension

A lightweight browser extension that provides a simple counter with
increment, decrement, reset, and target tracking functionality.

The extension is designed to help users track counts directly from the
browser without opening a separate application.

---

## 🚀 Features

- ➕ Increment the counter
- ➖ Decrement the counter
- 🔄 Reset the counter
- 🎯 Set a custom target
- 📊 Display current progress
- 🔔 Notification when the target is reached
- 🧩 Runs directly as a browser extension
- ⚡ Lightweight and easy to use

---
